用户希望 AI 工作时仍能正常使用自己的电脑，也希望切换 AI 后能沿用同一套流程。优先选择直接操作应用数据或调用应用 API 的后台 MCP。需要无界面后备方式时，可使用项目支持的 CLI 或脚本。

选择工具时看实际行为。即使通过 MCP 调用，模拟鼠标键盘、切换前台窗口或拖动控件也属于桌面控制。默认保留桌面给用户使用。遇到只有图形界面能完成的步骤，先完成可后台执行的部分，再交给用户具体文件和最少的手动步骤。
