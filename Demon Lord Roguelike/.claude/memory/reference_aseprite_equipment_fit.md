# Aseprite 装备贴身修整

魅魔第 06 批的配色和款式已经认可，臃肿来自肩甲、袖口、腰胯、护胫和外摆同时扩出身体，叠起来加宽了合成轮廓。以现有套装的装备帧做局部修整，母版身体、已认可配色与标志性饰件作为基准。

1. **建立身体和装备基准。** 只读检查源文件，定位装备帧并导出合成图和相关 Cel。按原画布坐标读取身体的逐行 alpha 外缘，胸侧要合并躯干与独立胸部 Cel，手腕、靴筒分别对齐对应前臂、小腿、手掌和脚。魅魔这批的装备帧为第 22 帧，其他角色按实际文件检查。
2. **逐件收外缘。** 在原生像素尺寸按部位定收量，沿上下方向渐变。先收肩甲、袖管、腰胯和靴筒，再把外摆收向腿部。贴身部件沿对应身体部件收，外摆从远离身体的一侧收。衣长、手脚接缝、前后遮挡和开衩按认可造型保留。
3. **保住包边和识别细节。** 把外轮廓、描边与金边一起向内移，固定胸徽、扣饰、花纹或开衩内缘。逐行压缩时可固定这些像素所在的区间，只重排两侧的原有像素。披肩、裙褶和飘带保留原有走向和必要的垂坠空间。魅魔 128×128 这一批多数贴身部件每侧约收 1–3 px，各套装备轮廓单行最大收窄 4–8 px。其他母版按实际体型和装饰判断。
4. **回查露肤和接缝。** 同尺度比较修前、修后的实际合成。若原先由衣物覆盖的身体像素在收边后露出，在原遮挡图层补回必要的原色像素。重点看胸侧、腰胯、腕口、踝口和鞋跟，同时检查包边有没有断、相邻部件有没有错位。
5. **在副本上保存并复核。** 只更新已有装备帧的目标 Cel。重新打开检查原有帧、身体 Cel、图层顺序和透明度，核对修过的像素颜色来自原部件。在原生尺寸和最近邻放大下各看一次，从保存后的装备帧重新导出效果图。按[装备交付规则](../skills/aseprite-equipment-from-preview/SKILL.md#正式交付路径)核对源文件、效果图和认可的原图裁片都直接位于母版旁的 `装备/`。哥布林两次误用了批次子目录，今后用文件名标识批次和修订版本，逐个核对实际父目录。

用 Aseprite Lua 批量落原色像素时，JSON 解码得到的 RGBA 像素值可能是浮点数。传给 `Image:drawPixel` 前用 `math.tointeger` 转成整数，并回读验证非透明像素，避免颜色通道被截断。Cel 偏移、工作副本和导出命令见[装备工具与 manifest](../skills/aseprite-equipment-from-preview/references/tools.md)。

## 哥布林 V1 的肩袖、胸腰和裤脚对齐（2026-11-12）

- **11 鳄鳞驯兽师。** 画面右臂对应 `ArmUp_R`、`ArmDown_R`、`Palm_R`。原袖斜得比右臂快，y104 的袖子在 x72–77，而上臂在 x69–73。y107 的袖口在 x74–77，漏掉前臂的 x72–73。沿原右臂逐行重配 `Equipment_Clay_Sleeve_R`，使袖根接上胸衣，袖口在 y107 盖住 x72–76，从 y108 起保留 V1 的前臂露肤和手掌。
- **04 银桦牧羊人。** 背心在 y101–102 占 x54–68，躯干占 x56–70，左侧多伸两格，右侧少盖两格。沿 `Body` 和 `Pelvis` 重配背心，左右袖按各自上臂收边。右裤脚 y124 原在 x66–67，完全错过 x68–71 的右小腿。按各自 `Calf` 重排两侧裤脚，y124 覆盖到 x55–58 和 x68–71，y125 起露出原脚。
- **V1 整批复检。** 02 琥珀蜂农的帽冠向右移 3px，罩纱上段随帽口对齐，胸腰与双袖按身体逐行重配。多套右袖的倾斜比母版右臂陡，按各套原有袖长逐行修正。16 套均回读第 21 帧，修正 01–03、05–14 和 16。04 的已修版与 15 的露臂羽披复核通过。
- **绘制和验收。** 用实际装备帧的非透明像素标出画布左右、肩肘腕、胸腰和膝踝。满画布 Cel 的 `(0,0,128,128)` 仅表示存储范围。先把每件装备和对应身体层叠看，逐行检查计划覆盖区的边界和露肤，再检查袖口与前臂、裤脚与脚的连续性。每批逐套查看保存后重新打开的 1× 与整数放大合成。校对字符网格、前帧和 Aseprite 校验通过后，仍需单独完成贴合检查。
