# 扭蛋（孕育）可抽职业速查表（29 个）

> **用途**：回答「某个职业多少血/多少攻击/什么攻击方式/自带什么能力」时直接查本表，不必翻 xlsx。
> **数据源**：`excel_creature_info`（id/攻击模式/基础属性/索敌/show_attribute）、`excel_attackmode_info`（攻击模块）、`excel_buff_info`（`creature_buff` 自带的固有能力）、`excel_language` 表 `CreatureInfo` 的 `content_1_*`（详情文案）。

- 7 个种族共 **29 个职业**，`creature_type=1` 即可扭蛋抽取单位；id 千位区分种族（人类 10xx / 骷髅 20xx / 史莱姆 30xx / 魅魔 40xx / 牛头人 50xx / 哥布林 60xx / 兽人 70xx）。
- 属性均为**基础值**（1 级、普通稀有度）：之后经等级加点（`LevelInfo.attribute_point`）、装备、稀有度 BUFF 增长。
- 全池统一：`MSPD=10`、`ASPD=0`、`MP/MPR/MPF` 未配置（魔力体系仅魔王用）。

## 列说明

| 列 | 含义 |
|---|---|
| HP / DR / ATK | 生命 / 护甲 / 攻击力（`excel_creature_info` 同名列） |
| CMP | 召唤魔力消耗（`CMP` 列，实际消耗还会叠加等级/稀有度增加倍率） |
| RCD | 召唤 CD（秒，`RCD` 列） |
| CRT / EVA / CDMG | 暴击率 / 闪避率 / 暴击伤害倍率，**均不在 CreatureInfo 表里**，见下方「固有能力」 |
| 索敌 | `attack_search_type` + `attack_search_range` |

## 固有能力（`creature_buff`）与暴击三属性

`CreatureInfo.creature_buff` 是**出生自带 BUFF**（`CreatureInfoBean.GetCreatureBuffs()` → `CreatureBean.GetListBuffData()`），不是属性列。暴击率/闪避/暴击伤害只从这里来：

| 属性 | 基础值（`CreatureBean.GetAttribute`） | 说明 |
|---|---|---|
| `CRT` 暴击率 | **0** | 命中时 `Random(0,1) ≤ CRT` → 伤害 × CDMG |
| `EVA` 闪避率 | **0** | 受击时 `Random(0,1) ≤ EVA` → 伤害归零 + miss 音效（**不吃该次命中附带的 DEBUFF**） |
| `CDMG` 暴击伤害 | **1.5**（= 150% 伤害） | BUFF 的 `trigger_value_rate` 按**绝对值 Flat 累加**（+0.5 → 2.0 = 200%） |

> CRT/EVA/CDMG 在 BUFF 管线里走 Flat 绝对值通道（不是百分比乘），见 `BuffEntityAttribute.EmitModifiers`。判定代码：`FightCreatureEntity.cs` 的闪避/暴击分支、`BaseAttackMode.StartAttack` 的快照。

| 固有能力 id | 效果 | 使用者 |
|---|---|---|
| 2000100001 | 闪避 50% | 6001 哥布林刺客 |
| 2000100003 | 闪避 20% | 2001 骷髅战士 |
| 2000200001 | 暴击率 50% | 6001 哥布林刺客 |
| 2000200002 | 暴击率 20% | 1002 人类弓箭手、2002 骷髅投手 |
| 2000500001 | 暴击伤害 +50%（→200%） | 6001、1002、2002 |

| 2000400001 | 条件（HP<50%）攻速 ×0.5 | 7001 兽人战士（⚠️ 与「攻速提升」描述不符，见下） |

### 已知待确认项

- **2000400001（兽人战士·狂暴-速）**：当前 `trigger_value_rate = -0.5`，ASPD 走 `PercentAdd` 通道 → `ASPD × 0.5`（**实际是降攻速**），与 BUFF 描述「攻击速度提升」相反；且 ASPD 基础值为 0，未加点时该 BUFF 实际无效果。**职业详情文案已按设计意图写成「攻击速度提升50%」**，配置数值由用户另行处理，此处仅记录现状。

## 维护入口

| 要改什么 | 改哪里 |
|---|---|
| 职业基础属性 / 攻击模式 / 索敌 / show_attribute | `excel_creature_info` |
| 攻击方式、元素异常概率（`buff` 列） | `excel_attackmode_info` |
| 固有能力（暴击/闪避/狂暴等） | `excel_creature_info.creature_buff` + `excel_buff_info` |
| 详情文案 | `excel_language` 表 `CreatureInfo` 的 `content_1_*`（`content_*` 是名字） |
| 扭蛋商品池/价格/解锁 | `excel_store_gashaponmachine_info`（见 gashapon-system SKILL） |

> Excel 是唯一真实源；改完需在 Unity 用 `ExcelEditorWindow` 导出，派生 `Assets/Resources/JsonText/*.txt` 才会更新。
