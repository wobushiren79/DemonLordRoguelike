# 回填 Aseprite 母版

## 选定母版与素材

- 以实际母版目录 `../资源/生物/<生物>/` 为基准。哥布林武器先读[哥布林武器回填规则](references/goblin-weapons.md)，眼睛和嘴巴先读[哥布林身体部件回填规则](references/goblin-body-parts.md)；骷髅头部先读[骷髅身体部件回填规则](references/skeleton-body-parts.md)；牛头人牛角、眼睛和鼻环先读[牛头人回填规则](../aseprite-minotaur-backfill/SKILL.md)；史莱姆眼睛先读[史莱姆回填规则](../aseprite-slime-backfill/SKILL.md)；兽人眼睛和嘴巴先读[兽人回填规则](../aseprite-orc-backfill/SKILL.md)。其他素材按各自已确认的规则定位目标图层及帧。
- 人类发型、眼睛和嘴巴先读[人类身体部件回填规则](../aseprite-human-backfill/SKILL.md)，按源帧保留前后发及眼嘴搭配。
- 魅魔发型、眼睛、角和翅膀先读[魅魔身体部件回填规则](../aseprite-succubus-backfill/SKILL.md)，核对独立部件层、前后发顺序和左右翼配对。
- 只处理用户选定的子文件、款式或类型。新增时核对源帧、完整源图层路径和已确认的素材名称。更新或删除时先定位母版的目标帧和图层，名称只用于辅助定位。
- 回填套装时，从共用装备文件按实际帧号读取选定套装的各件装备 Cel，按制作交付的图层清单排除用于合成预览的身体 Cel。旧单套文件按其实际源帧和已确认的装备层读取。
- 用 [Aseprite 基础工具](../aseprite-pixel-editor/SKILL.md) 检查画布、颜色模式和实际 Cel。导出/写入复用 [独立 Cel 与 manifest 工具](../aseprite-equipment-from-preview/references/tools.md)。完整路径重名时，分别检查源文件和母版的组内顺序，并为目标层填写实际 `layer_indices`。正式母版与子文件作为输入，先保存到不同路径的候选副本。

## 身体部件与武器优先补位

- 制作身体或武器子文件，以及回填母版时，都在各自的目标文件内从第 1 帧向后扫描对应图层。该层无 Cel 或 Cel 图像全透明，并且该位置没有已有登记，才是空位。有任何非透明像素的 Cel 即使隐藏或未登记也占位。登记项即使实际 Cel 为空也占位，先核对登记与素材来源。其他图层有素材不会占用本层的空位。
- 按选款顺序逐款取最早可用空位。已确认的多层组合、前后发、左右翼或成对武器，在同一帧的所有目标层都空时才放入；仅确认一层时按该层找空位。每放一组都更新占位，只有没有合适空位的剩余款式才从末尾追加。子文件源帧号不等于母版目标帧号。装备沿用其原有落位规则。牛头人独立鼻环是例外，在两份 Aseprite 中按 `NoseRing_1` 补位，见[牛头人回填规则](../aseprite-minotaur-backfill/SKILL.md#新帧的固定身体与落位)。
- 写回前核对候选的独立目标 Cel 和确认清单。为合成预览临时加的未选部件只保留在预览副本，不能写入正式子文件的素材层占位。现存非透明 Cel 先按已有素材处理；如需清理历史预览残留，先核实其来源与实际像素，再按本次授权处理。

## 新增帧时复制基础身体

- 所有物种新增回填帧或补齐已有帧的基础身体时，只复制该物种的固定身体部件。按物种规则和实际母版核对基础姿势、固定部件图层及各层来源帧。可自定义部件的图层保留，Cel 留空供后续回填，即使基准帧中该层已有可见内容也跳过。只有本次明确选中的自定义部件才写入对应图层。旧装备、武器和特效也排除在基础身体之外。
- 使用 `mode=append` 时，在 manifest 的 `copy_cels` 中按完整图层路径列出固定身体 Cel 和各自的 `from_frame`。复制到新帧的原有图层，保留像素、画布坐标、透明度和 Z 顺序，再用 `cels` 写入本次素材。补已有空位时用 `mode=replace`，保留该帧的其他已有 Cel，只在确实缺失的固定身体图层补齐所需 Cel。
- 重新打开候选母版，从实际保存的帧查看合成效果，核对固定身体齐全且与本次素材对齐，检查本次未选中的自定义部件在新增帧没有 Cel。如果素材所在层默认隐藏，在预览时开启该层，并在交付时说明在 Aseprite 中如何显示。正式母版沿用原有的图层可见性。

## 同步素材名字表

- 工作簿固定为 `<母版所在目录>/<生物>_素材名字.xlsx`。存在则沿用同一文件和已有登记表，保留其他工作表和记录。缺少登记表时在该工作簿中创建 `素材名字` 工作表，第一行列名为 `素材类别`、`素材类型`、`帧号`、`图层路径`、`素材名称`。类别填 `装备`、`武器` 或 `身体部件`，类型按已确认分类填写。素材名称保存为文本，供后续导入工程时使用。
- 以「母版帧号 + 完整图层路径」定位记录。帧号从 1 开始。同一帧上的不同图层可分别登记。登记范围是本次回填、更新或明确要求补录的素材，随新帧复制的基础身体只用于查看搭配。母版上已有内容的 Cel 即使尚未登记也占位。
- 新增时登记实际落位。更新和改名保留原位，更新对应行。重跑时用已登记的名称、类型和实际 Cel 核对同一款，确认已回填即可复用原位。发现同名有歧义或表有记录而图已空，先核对具体目标再更新。
- 删除时用官方 Aseprite Lua `sprite:deleteCel(layer, frameNumber)` 删除指定 Cel，同时从 Excel 删除同一帧、同一图层的记录。保留整个时间轴帧和其他图层。若用户已手动清除该 Cel，核对目标确实为空后只同步删表行。
- 按[项目 Excel 读写规则](../../../CLAUDE.md#excel-读写规则)通过 `run-python.ps1` 和 `openpyxl` 读写，已存在的工作簿写回前备份，工作簿和文件流用完即关闭。

## 预览、写回与核对

1. 记录原母版及现有名字表的哈希。在临时目录准备候选母版、名字表和帧位清单。逐项回读新 Cel 的像素、位置、透明度和 Z 顺序。核对其余 Cel、图层顺序、原帧时长和标签范围。工具的 `verify through=N` 只适用于前 N 帧完全保留的情况，补位、更新或删除需按实际目标帧与图层做差异核对。
2. 用户明确要求回填、更新或删除指定素材时，候选文件核验通过后直接写回。用户要求先预览或明确要求确认后再写回时，展示候选结果并等确认。写回前复核原文件哈希，如有后续修改，以最新母版和名字表重新核对受影响的帧位。
3. 候选母版和表都回读通过后成对写回。保留原文件备份到两者均核验完成。若写回中途失败，恢复已经替换的文件，首次创建的表按原先不存在的状态恢复。最终核对新增、更新、删除的 Cel 与表行一致，并确认 Excel 经 `git hash-object --no-filters` 可读。
4. **交付前执行[清理与验收](../aseprite-body-parts/SKILL.md#清理与验收)。** 回填是本次最后一步时，负责清掉制作和回填各阶段共用或各自建立的批次临时目录，包括旧预览、候选和备份。逐个确认目录已删除，再发最终总结。

交付母版和名字表路径、每项素材的母版帧号与图层。需要展示合成效果时，在清理前展示，或使用用户明确要求保留的正式预览。用户要求生成 Spine 导入文件时，按这份对应关系使用 [Aseprite 导出 Spine 素材](../aseprite-spine-export/SKILL.md)。
