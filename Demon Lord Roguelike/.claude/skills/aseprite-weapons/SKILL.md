# 制作 Aseprite 武器

## 选定唯一的武器源文件

- 从实际母版位置派生 `<母版所在目录>/武器/<母版名>_武器.aseprite`，与 `身体/` 同级。首次以母版为起点；同一母版已有唯一武器文件时沿用它。多个候选或归属不明时先确认源文件。
- 所有类型和款式放在同一个武器文件中。每款默认在末尾追加一帧，以独立图层 Cel 保存。修整已收录款式时改对应帧的武器 Cel。默认沿用原时间轴标签，新增帧以编号定位。
- 新生成武器时，如果用户当次尚未选定生成方式，按[项目的像素图生成方式](../../../CLAUDE.md#像素图生成方式)用中文列出三种编号选项，优先推荐第 1 种「生图后转换像素图」。收到选择后再开始生图、转换或绘制。用户当次已明确选定一种或多种方式时，直接按选择执行。
- 比较多种方式时，使用相同的造型主题、附件定位基准、身体基准和预览倍率，并为每种方式的候选编号。

## 检查母版、骨骼挂点与附件位置

1. 用 [Aseprite 基础工具](../aseprite-pixel-editor/SKILL.md) 检查画布、颜色模式、原图层、帧、Cel 偏移和切片。选定能表达该武器展示姿势的基准帧或从原帧组合身体。找出同角色、同展示方式的原武器，记录其原生宽高、画布位置和与躯干、手臂、手掌的绘制顺序。
2. 分别记录 Spine 武器槽绑定的骨骼挂点和原附件在画布上的显示位置。手持款以实际接触手掌的位置为准，可用母版拿取标记、切片 pivot 或原武器握柄核对。胸前、背负等有独立偏移的款式以同类原附件的显示中心定位，沿用它相对骨骼的偏移。换算时处理 Spine 向上的 Y 轴、父骨骼变换和附件旋转，并与母版 Cel 实测结果交叉核对。只能从原画估计时，标明估计并检查合成预览。哥布林的实例见[哥布林武器挂点与附件位置](references/goblin.md)。
3. 记录画布对齐点 `(tx, ty)` 和每张透明武器图里的局部对齐点 `(ax, ay)`。手持款取实际握点，胸前等偏移款取与原附件一致的中心。导入偏移为 `(tx - ax, ty - ay)`。裁切 PNG 时同步扣掉裁切起点，用母版的像素坐标约定调整留边，使 Cel 偏移落在整数网格。双手或分件武器还需检查副手接触和前后遮挡。
4. 按选定的同类原附件原生宽高与比例绘制透明武器，沿用其朝向、光照和描边。复用原附件的绘制顺序，按需要将武器前后部分独立分层。新帧只显示本款武器，身体和手掌 Cel 保持原像素、位置、透明度和相对顺序。

## 用副本组装并验证

- 候选副本、透明 PNG、预览和编号到帧号的对应关系放在本次临时目录。用官方 Aseprite CLI/Lua 保存，可复用 [Cel 导出、manifest 与验证命令](../aseprite-equipment-from-preview/references/tools.md#新增一帧或局部替换)。追加时显式列出需要的基准 Cel，排除原武器 Cel；有同名图层路径时，用官方 Lua 按各级组内的顺序定位，保留原层名。
- 记录输入哈希、原帧数和原标签起止帧。候选输出路径与输入不同。若 Aseprite 追加帧时延长了原标签，用官方 Lua 恢复其范围。保存后重新打开，校验新增帧数、帧与编号映射、原帧和原标签、原输入哈希，以及新增帧中的身体像素、武器层独立性、附件位置和尺寸。
- 用保存后重新打开的 Aseprite 原生渲染输出预览。在原生倍率和整数放大下检查武器轮廓和画布边缘。手持款检查手掌接触与握柄遮挡。胸前等偏移款与同类原武器按同一倍率比较，检查显示位置、相对角色的大小和前后遮挡。给每款标上唯一编号，在对话中展示角色装备后的实际预览。

## 按预览选择写回

1. 用户要求挑选或查看候选效果时，保留合并后的候选 Aseprite 和预览，收到明确选择后再写正式文件。用户已授权保留指定款式或整批交付时，按该授权写回。
2. 写回前重查目标路径和输入哈希。正式武器文件有后续更新时，以最新版本为基准追加确认的款式。只写入选定款式，重新验证后将副本移入首次目标，或用 `[System.IO.File]::Replace` 更新已有的同一个正式文件。
3. 确认正式目录内只有该母版的这一份武器 Aseprite，重新打开文件并核对所选款式。按实际正式帧号同步武器帧名表。交付 Aseprite 和 Excel 路径、确认的款式编号与帧号，验证后清理本次中间文件和备份。

## 同步武器帧名表

- 每次正式写入武器后，在该 Aseprite 的同级 `武器/` 目录创建或更新唯一的 `<母版名>_武器.xlsx`。沿用已有工作簿及 `武器帧` 工作表，保留其他工作表。仅保存候选预览时，使用临时编号记录。
- `武器帧` 工作表至少包含 `帧号`、`武器名称`，可加 `武器类型`。使用正式 Aseprite 从 1 开始的实际帧号，每个含武器的帧一行，按帧号升序排列。重新导入、修整、重命名或移动武器帧后同步对应记录，保留已确认的名称，除非用户明确要求改名。补录正式 Aseprite 自带的原武器帧时，从母版、Spine 附件与道具名称、已有帧名表或已确认的预览等可核实来源确定名称。名称无法核实时标记「待确认」，并告知对应帧号。
- 按[项目 Excel 读写规则](../../../CLAUDE.md#excel-读写规则)和 [excel-io](../excel-io/SKILL.md) 的 `openpyxl` 操作规范读写，Python 通过项目 `run-python.ps1` 执行。现有工作簿写回前先备份。保存后重新打开 Aseprite 和 Excel，核对武器帧清单、名称及帧号，确认无重复或漏记。关闭工作簿及文件流，确认 Git 可读，再清理本次备份。
