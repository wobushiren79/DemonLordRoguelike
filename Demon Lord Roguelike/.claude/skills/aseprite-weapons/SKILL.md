# 制作 Aseprite 武器

## 选定唯一的武器源文件

- 从实际母版位置派生 `<母版所在目录>/武器/<母版名>_武器.aseprite`，与 `身体/` 同级。首次以母版为起点；同一母版已有唯一武器文件时沿用它。多个候选或归属不明时先确认源文件。
- 所有类型和款式放在同一个武器文件中。按[目标层补位规则](../aseprite-master-backfill/SKILL.md#身体部件与武器优先补位)从第 1 帧向后扫描，对应武器层无 Cel 或全透明且无帧名登记才可补位。成对左右武器只选两个目标层都空闲的最早帧，单件只检查其目标层。找不到合适空位时才追加。修整已收录款式时改对应帧和图层的 Cel，沿用原时间轴标签。
- 新生成武器时，如果用户当次尚未选定生成方式，从[项目的像素图生成方式](../../../CLAUDE.md#像素图生成方式)读取当前三种编号选项并用中文列出，优先推荐第 1 种。收到选择后再开始生图、转换或绘制。用户当次已明确选定一种或多种方式时，直接按选择执行。
- 比较多种方式时，使用相同的造型主题、附件定位基准、身体基准和预览倍率，并为每种方式的候选编号。

## 检查母版、骨骼挂点与附件位置

1. 用 [Aseprite 基础工具](../aseprite-pixel-editor/SKILL.md) 检查画布、颜色模式、原图层、帧、Cel 偏移和切片。选定能表达该武器展示姿势的基准帧或从原帧组合身体。找出同角色、同展示方式的原武器，记录其原生宽高、画布位置和与躯干、手臂、手掌的绘制顺序。
2. 分别记录 Spine 武器槽绑定的骨骼挂点和原附件在画布上的显示位置。手持款以实际接触手掌的位置为准，可用母版拿取标记、切片 pivot 或原武器握柄核对。胸前、背负等有独立偏移的款式以同类原附件的显示中心定位，沿用它相对骨骼的偏移。换算时处理 Spine 向上的 Y 轴、父骨骼变换和附件旋转，并与母版 Cel 实测结果交叉核对。只能从原画估计时，标明估计并检查合成预览。哥布林的实例见[哥布林武器挂点与附件位置](references/goblin.md)。
3. 记录画布对齐点 `(tx, ty)` 和每张透明武器图里的局部对齐点 `(ax, ay)`。手持款取实际握点，胸前等偏移款取与原附件一致的中心。导入偏移为 `(tx - ax, ty - ay)`。裁切 PNG 时同步扣掉裁切起点，用母版的像素坐标约定调整留边，使 Cel 偏移落在整数网格。双手或分件武器还需检查副手接触和前后遮挡。
4. 按选定的同类原附件原生宽高与比例绘制透明武器，沿用其朝向、光照和描边。复用原附件的绘制顺序，按需要将武器前后部分独立分层。保留原有身体、手掌和其他已有 Cel。未选武器或其他可换部件只在独立预览副本临时显示，不写进正式子文件占用目标层空位。

## 用副本组装并验证

- 候选副本、透明 PNG、预览和编号到帧号的对应关系放在本次临时目录。用官方 Aseprite CLI/Lua 保存，可复用 [Cel 导出、manifest 与验证命令](../aseprite-equipment-from-preview/references/tools.md#新增一帧或局部替换)。使用 `mode=replace` 补位时保留同帧其余 Cel，仅补缺失的固定身体层。只有空位不足才用 `mode=append`，`copy_cels` 只列固定身体层，所选武器写到 `cels`。完整图层路径重名时，在 manifest 按实际分组顺序填写 `layer_indices`。
- 记录输入哈希、原帧数和原标签起止帧。候选输出路径与输入不同。若 Aseprite 追加帧时延长了原标签，用官方 Lua 恢复其范围。保存后重新打开，校验编号与实际帧、独立目标 Cel、附件位置和尺寸。追加前旧帧保持原样，补位帧仅有目标武器 Cel 和明确补齐的固定身体空位变化。核对原标签和输入哈希。
- 用保存后重新打开的 Aseprite 原生渲染输出预览。在线条、描边及分件衔接处执行[完美像素检查](../aseprite-pixel-editor/SKILL.md#完美像素检查)，同时检查武器轮廓和画布边缘。手持款检查手掌接触与握柄遮挡。胸前等偏移款与同类原武器按同一倍率比较，检查显示位置、相对角色的大小和前后遮挡。给每款标上唯一编号，在对话中展示角色装备后的实际预览。

## 按预览选择写回

1. 用户要求挑选或查看候选效果时，保留合并后的候选 Aseprite 和预览，收到明确选择后再写正式文件。用户已授权保留指定款式或整批交付时，按该授权写回。
2. 写回前重查目标路径和输入哈希，以最新版本和名表重扫最早空位。回读候选核对实际目标帧、独立图层和确认编号一致，再将副本移入首次目标，或用 `[System.IO.File]::Replace` 更新已有的同一个正式文件。
3. 确认正式目录内只有该母版的这一份武器 Aseprite，重新打开文件并核对所选款式。按实际正式帧号同步武器帧名表。交付 Aseprite 和 Excel 路径、确认的款式编号与帧号，验证后清理本次中间文件和备份。

## 同步武器帧名表

- 每次正式写入武器后，在该 Aseprite 的同级 `武器/` 目录创建或更新唯一的 `<母版名>_武器.xlsx`。沿用已有工作簿及 `武器帧` 工作表，保留其他工作表。仅保存候选预览时，使用临时编号记录。
- `武器帧` 工作表至少包含 `帧号`、`武器名称`，可加 `武器类型`。记录正式 Aseprite 从 1 开始的实际帧号，按帧号升序排列。每款独立武器或成对组各一行，同帧多款用 `图层路径` 区分。旧登记仅含帧号时，结合实际 Cel 和确认清单核对登记所占图层，无法确认的潜在位置暂不当作空位。重新导入、修整、重命名或移动后同步相应记录，保留已确认的名称。补录原武器时，从母版、Spine 附件与道具名称、已有帧名表或已确认预览核实名称；名称无法核实时标记「待确认」，并告知对应帧号。
- 按[项目 Excel 读写规则](../../../CLAUDE.md#excel-读写规则)和 [excel-io](../excel-io/SKILL.md) 的 `openpyxl` 操作规范读写，Python 通过项目 `run-python.ps1` 执行。现有工作簿写回前先备份。保存后重新打开 Aseprite 和 Excel，核对武器帧清单、名称及帧号，确认无重复或漏记。关闭工作簿及文件流，确认 Git 可读，再清理本次备份。

用户确认子文件中的款式并要求写入母版时，使用[回填 Aseprite 母版](../aseprite-master-backfill/SKILL.md)，按实际母版帧号同步母版同级的素材名字表。
