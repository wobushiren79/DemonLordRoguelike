# 哥布林武器挂点与附件位置

- 母版为 `../资源/生物/哥布林/哥布林.aseprite`，以 Unity 项目目录为基准。已核对版本为 RGB、128×128、20 帧，无切片。SHA-256 为 `A7B37C1DF3970E14C9F51D37EA80778D3A390182506BF0CD86A826B71DF63F29`。站姿、Cel 或骨骼版本变动后重新测量。
- 同目录的 `Goblin.json` 将 20 个 `Weapon_R_*` 槽绑定到 `Weapon_R`，父骨骼为 `Palm_R`。在这个母版站姿，Spine 附件与母版武器 Cel 同向、同尺寸。设 Cel 为 `(x, y, w, h)`，附件局部偏移为 `(dx, dy)`，画布附件中心为 `(x + w/2, y + h/2)`，骨骼挂点为 `(x + w/2 - dx, y + h/2 + dy)`。金刀、木弓及其余原武器都可反算出挂点 `(76.5, 111)`。
- 手持款按握柄对齐该站姿的右手。右掌 Cel 是 `(74, 109, 5, 4)`，武器握柄可放在右掌下，使手掌遮住握柄。画布以左上为原点，`76.5` 在第 76 列像素中心，`111` 在两行的边界。新图局部握点用同样的半整数 X 和整数 Y，使 Cel 偏移为整数。
- 大型爆炸物按胸前抱持布局。`Weapon_R_17` 至 `Weapon_R_20` 的附件相对骨骼向左偏移约 12.5–13 像素，显示中心落在躯干前。`Walk2` 起始姿势中双手位于身前，原炸弹显示在双手之间。`Weapon_R_8` 猩红之酒沿用手持小瓶的布局。

- 胸前新款用表中最相近旧款的显示中心、原生宽高和可见轮廓校准。按原 `Weapon_R_1` 的绘制顺序放置独立层，位于 `Body`、`Pelvis` 之上及 `ArmDown_L`、`ArmUp_L`、`Palm_L` 之下，原 Cel 的 `zIndex` 为 `0`。母版中的原武器层默认隐藏，检查新层是否可见。
- 新帧复制已核对的身体、眼睛和嘴 Cel，排除原武器及箭、弹道装饰。在同倍率原生合成中与旧款比较，核对附件是否出画、胸前轮廓和手臂遮挡。手持款还应核对握点附近的实际像素和手掌接触。
