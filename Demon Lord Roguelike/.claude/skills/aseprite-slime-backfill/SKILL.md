# 史莱姆眼睛回填

按[通用母版回填规则](../aseprite-master-backfill/SKILL.md)核验文件、登记素材并成对写回。以下路径从 Unity 项目目录起算：

| 用途 | 文件 |
|---|---|
| 母版 | `../资源/生物/史莱姆/史莱姆.aseprite` |
| 已确认眼睛 | 母版目录下的 `身体/史莱姆_身体.aseprite` |
| 素材名字表 | 母版同级的 `史莱姆_素材名字.xlsx` |

## 核对源帧与落位

1. 用 [Aseprite 基础工具](../aseprite-pixel-editor/SKILL.md)检查母版和身体子文件的画布、颜色模式与 Cel。当前母版为 64×64 RGBA，源和目标都使用顶层 `Eye_1`。根据选款清单定位实际源帧。预览编号、子文件帧号和母版帧号分别记录，尤其要核对去掉部分款式后重新连续排列的帧。
2. 按用户确认的顺序回填，未指定顺序时按源帧升序。用[独立 Cel 与 manifest 工具](../aseprite-equipment-from-preview/references/tools.md)提取 `Eye_1`，保留像素、画布位置、不透明度和 Z 顺序。一款眼睛放入一个 Cel。新增时从母版当前末帧之后连续追加，一款一帧。重跑时按素材名称、图层及实际 Cel 核实已登记的款式和原帧位。
3. 新帧的 `copy_cels` 只复制母版第 1 帧的 `Body_1`，当前 Cel 位于 `(17,39)`、尺寸 30×25。`cels` 只写入本款 `Eye_1`，跳过基准帧的旧眼睛和 `Hat_1`、`Hat_1_Bg` 等可自定义层。保留原帧、图层顺序、可见性与标签范围。
4. 保存候选并重新打开，逐帧核对新眼睛与源 Cel 一致、身体与基准帧一致，帽子层在新增帧无 Cel。用原生尺寸及最近邻整数倍检查非透明眼部像素与身体轮廓的贴合。母版当前图层全部隐藏，预览副本只开启 `Body_1` 和 `Eye_1`，正式文件沿用原可见性。交付时提示用户开启这两层查看。

## 名字登记与交付

沿用[通用素材名字表结构](../aseprite-master-backfill/SKILL.md#同步素材名字表)。每款眼睛登记一行，类别为 `身体部件`，类型为 `眼睛`，帧号为从 1 开始的实际母版帧号，图层路径为 `Eye_1`，素材名称为确认的款名。按[通用写回规则](../aseprite-master-backfill/SKILL.md#预览写回与核对)成对写回母版和名字表，并交付款名、实际帧号及合成预览。收到 Spine 导出请求时使用 [Aseprite 导出 Spine 素材](../aseprite-spine-export/SKILL.md)。
