# 史莱姆眼睛与帽子回填

按[通用母版回填规则](../aseprite-master-backfill/SKILL.md)核验文件、登记素材并成对写回。以 Unity 项目目录的 `../资源/生物/史莱姆/` 为基准。

| 用途 | 相对史莱姆目录 |
|---|---|
| 母版及登记表 | `史莱姆.aseprite`、`史莱姆_素材名字.xlsx` |
| 眼睛来源 | `身体/史莱姆_身体.aseprite` |
| 帽子来源及子帧登记 | `装备/A史莱姆_装备.aseprite`、`装备/A史莱姆_装备.xlsx` 的 `装备帧` 工作表 |

用 [Aseprite 基础工具](../aseprite-pixel-editor/SKILL.md)读取源文件及当前母版。画布为 64×64 RGBA，原生图层自下向上为 `Hat_1_Bg` → `Body_1` → `Eye_1` → `Hat_1`。固定身体取母版第 1 帧的 `Body_1`，核对其位置和半透明像素；现有基准 Cel 位于 `(17,39)`，尺寸 30×25。按用户指定顺序处理所选款式，未指定顺序时按实际子帧升序。

## 眼睛回填

1. 根据选款清单定位身体子文件的 `Eye_1`。预览编号、实际子帧与母版帧分别记录。用[独立 Cel 与 manifest 工具](../aseprite-equipment-from-preview/references/tools.md)提取该层，保留像素、画布位置、不透明度和 Z。
2. 每款眼睛占一个 Cel，按[目标层补位规则](../aseprite-master-backfill/SKILL.md#身体部件与武器优先补位)重新扫描母版的 `Eye_1`。补位帧保留原帽子和其他 Cel，缺失的固定身体从基准帧补齐。没有可用眼睛位时追加一帧，仅复制 `Body_1` 并写入本款眼睛。重跑时核对已有名称、图层和实际 Cel 后复用原位。
3. 从保存后的母版核对目标眼睛与源 Cel。开启预览副本的 `Body_1` 和 `Eye_1`，以 1× 及最近邻整数倍率检查眼部位置。名字表每款登记一行，类别 `身体部件`、类型 `眼睛`、图层 `Eye_1`。

## 帽子回填

1. **核对前后层。** 用装备帧表中的帽名和实际子帧定位原稿，提取同一款的两个帽层。额前的帽檐、徽饰归 `Hat_1`，身体后方或埋入胶体的部分归 `Hat_1_Bg`，由半透明的 `Body_1` 自然透出。纯 BG 款只写后层，纯前景款只写前层。两层款同时写入同一个母版帧，装备 Cel 的 Z 为 `0`。
2. **识别已回填的帽子。** 按[同款比对规则](../aseprite-master-backfill/SKILL.md#回填前比对同款素材)核对名字表和母版双帽层的组合，包括每层是否有 Cel、实际像素、偏移、不透明度及 Z。子文件可能继承母版旧帽。若本次所选款式在母版已有唯一完整匹配，复用原母版帧，补齐本款缺少的登记。多处匹配时先核实具体帧和来源。同款帽子只要其中一层有差异或缺失，就按[通用同款比对规则](../aseprite-master-backfill/SKILL.md#回填前比对同款素材)询问用户是否覆盖。
3. **双帽层共同占位。** 依[装备选帧规则](../aseprite-equipment-from-preview/SKILL.md#选帧和装备图层)，在当前母版从第 1 帧起扫描。只有 `Hat_1_Bg` 和 `Hat_1` 都没有 Cel、也都没有帽子登记时才可补入一款。任何一层已有 Cel（含隐藏层）或登记都占用该帽位，单层帽也独占这一帧的帽位。每放一款就更新占位，空位用完才追加。子帧与母版帧号分别按各自文件记录。
4. **保留固定身体与已有表情。** 补位时原样保留 `Eye_1` 和已有 `Body_1`，仅补缺失的固定身体。追加母版帧只复制基准 `Body_1`，眼睛位留给独立眼睛素材。需要带基础眼睛的试戴图时，可在预览副本叠加基准眼睛。装备子文件中的展示用身体和眼睛留在子文件。
5. **回读并登记。** 重新打开候选母版，逐款核对两个帽层的 Cel 存在性、RGBA、偏移、不透明度和 Z。回查旧 Cel、身体透明度、层序、可见性、帧时长与标签范围。按原生层序导出 1× 及最近邻整数放大的合成图，检查帽檐、入体位置和眼区。在母版 `素材名字` 表填 `装备`、`帽子`、实际母版帧号、完整图层路径和款名。双层帽按两条图层路径分为两行，同帧同名；单层帽仅登记实际使用的图层。装备子表仍为一帽一行，列出实际使用的帽层。

## 写回与交付

依[通用写回与核对](../aseprite-master-backfill/SKILL.md#预览写回与核对)成对写回母版与名字表。交付本批款名、实际子帧与母版帧的对应关系、使用图层和合成预览。母版沿用原图层可见性，若默认隐藏，查看帽子时开启 `Hat_1_Bg`、`Body_1`、`Eye_1`、`Hat_1`。收到 Spine 导出请求时使用 [Aseprite 导出 Spine 素材](../aseprite-spine-export/SKILL.md)。
