- 默认沿用用户已确认的“优先保留母版身体”：身体像素、姿势、朝向、部件位置不变，装备适配身体。当前用户另有明确要求时，以当前要求为准，不重复询问已确认的取舍。

- 用户提供可读的本地图片时直接读取。此次原图名为 `16套职业装像素哥布林.png`；文件位置由当前输入解析，不固化桌面或盘符路径。原图不可读时可用已保存的对应 `_参考.png`，不能仅凭文件名猜另一张图。
- 本地任务直接交付到母版旁的装备目录。总结给出实际路径和装备帧；已经写入本地的结果不要求用户再下载一遍。

## 分件取色与对齐

1. 先核对套装编号与原图行列。此次原图为 1086×1448、4×4，单格宽 271.5：共享边界按 `round(i*W/列数)` / `round(j*H/行数)` 计算，避免对固定格宽累计取整而漏列或重叠；实际角色若跨格，应按完整轮廓调整。原样保存的参考截图不抠图、不缩放、不调色。
2. 每件记录 `套装号、源图局部 box/多边形、脸部等排除区、目标 x/y/宽/高、图层名`。先遮罩再裁切，分件最近邻缩到母版原生尺寸；不要把整个人物统一缩小后覆盖母版，也不要给所有帽子套一个尺寸。
3. 帽口以眼、额头、脸和耳根的实际位置定位。`Head` 的矩形包含横向耳部，不能把它的全宽当头盔内宽。先配准帽口再确定帽顶，帽饰可在轮廓外延伸；帽口始终检查原眼、嘴的露出与遮挡。
4. 肩甲依左右肩分别落点，胸衣贴合 Body，腰带贴合 Pelvis，膝甲/护腕跟随对应肢体。衣摆依母版腰、膝、踝之间的距离适配，不能把参考图长袍高度直接搬过来遮掉脚。此版本脚底到 y=128，勿越界裁掉脚或拉长身体腾空间。
5. 已认可铁甲卫兵的装备 `(x,y,宽,高)` 可作比例复核例：头盔 `(60,84,13,11)`、胸甲 `(57,102,13,9)`、左肩 `(51,98,11,7)`、右肩 `(69,99,6,6)`、腰裙 `(55,113,17,10)`、腰带 `(56,111,16,5)`。这些是该套设计的实测值，不是别的帽子或衣服的目标尺寸。
6. 批量制作时先完成代表套装的完整适配与部件检查，再沿用身体基准处理其他套。已获继续整批制作的授权时自主推进；不要把每套都变成一次重复审批。

## 遮罩与分层中的易错点

| 风险 | 处理与复核 |
|---|---|
| 灰底混入、银色装备被误删 | 在局部多边形内，优先从图像外缘对相近灰底做连通区域删除；不要全图删除灰色。连通删除也可能侵蚀与背景相连的银甲，必须逐件检查边缘与高光。 |
| 去皮肤时删掉绿叶、青绿衣服 | 绿色判据只能是候选遮罩；苔叶游侠等绿色装备改用精确多边形，区分叶片、青绿布料与皮肤。暗绿色皮肤与黑描边也可能漏过阈值，需人工检查。 |
| 帽口带入参考人物的眼睛、牙齿、脸部黑块 | 显式画出脸部排除区，去绿色不足以去掉白眼和黑面孔。海盗帽下缘曾残留参考图白眼像素，必须检查单独帽子 PNG。 |
| 盔甲或帽边带入相邻衣物碎片 | 检查每个部件的孤立像素与下缘，特别是头盔下方的毛领、帽旁耳部和肩甲外侧手臂；缩小后一个残点也可能很明显。 |
| 药瓶、腰包、垂带出现双份 | 若缩放后的腰裙/胸衣已有附件，从同一目标像素块拆出附件层，并清除底层对应像素，保证合成不变；不要在包含附件的底层上再叠加另一份重采样附件。 |
| 复用套装时旧装备残留 | `replace` 未列出的层会保留。复用已穿衣副本时清点全部装备层，对不用的装备 Cel 在目标帧清空，不能只覆盖头盔和胸甲。现有 apply 可用 1×1 全透明 RGBA PNG 替换该 Cel；不要删除原身体层或其他帧。 |
| 图层顺序与 Python 预览不一致 | 原有装备层保持原栈位置，新建层默认追加；不能假设 manifest 条目顺序就是实际图层顺序。用保存后的原生导出核对遮挡。 |

此次灰底连通删除曾用 `58 < min(R,G,B)`、`max(R,G,B) < 180`、`max-min < 19` 作为候选；绿色皮肤候选曾用 `G-R>2`、`G-B>5`、`G-B>0.75*(G-R)`。它们只适用于本次原图的起始判断，不是通用抠图算法；必须结合部件多边形、排除区、绿色装备例外与拆件检查，不能仅凭数值自动验收。

## 验收与后续复用

- 同时查看单件透明 PNG、全套合成以及 1x/最近邻整数放大效果，重点检查帽口、耳根、肩颈接缝、膝踝和衣摆。批量总览使用相同裁切范围、背景与倍率，不能逐套缩放至满格而掩盖尺寸差异。
- 按[工具文档的身体核对](tools.md#装备帧身体核对)比较目标帧身体。此版本应有 17 个身体 Cel 未变；旧帧校验和母版哈希一致仍须分别通过，不能互相替代。
- 采用纯原图像素取色流程时，可校验装备非透明像素 RGB 属于对应原图颜色集合，防止意外调色、插值或量化。颜色集合一致不能证明高光位置、形状或对齐正确，仍需视觉检查。
- 正式效果 PNG 必须来自保存后重新打开的 `.aseprite`。核对三件交付、参考图编号和实际装备帧；保留用户认可版本，修订另存明确目录，不覆盖母版。
