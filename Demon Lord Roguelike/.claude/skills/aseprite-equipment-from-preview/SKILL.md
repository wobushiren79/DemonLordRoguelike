# 根据预览图制作 Aseprite 装备

## 正式交付路径

从实际母版位置派生 `<母版所在目录>/装备/A<母版名>_装备.aseprite`。**同一母版的所有套装共用一份以 `A` 开头的可编辑装备文件。** 首次制作以母版为起点。若已有明确归属的旧名共用文件，核对其已收录套装与帧号，确认新路径可用后改名并回读，原帧号及其 PNG 名称照旧。新路径已存在或有多个归属不明的候选时，先核对内容和版本。历史单套文件作为待归并素材和参考图的来源。

每套另交付两张 PNG，文件名按它在**正式共用文件中从 1 开始的实际帧号**命名。例如哥布林第 11 帧交付 `哥布林_帧11_预览.png` 和 `哥布林_帧11_参考.png`，与 `A哥布林_装备.aseprite` 一起直接放在 `../资源/生物/哥布林/装备/`。效果预览来自保存后的装备帧。新参考图由用户提供或确认的原图裁片制作，默认压到该裁片 PNG 文件大小的 **1/10 以内**，宽、高和字节数同时受 Git 历史缩略图限制。重做已有帧时取该帧最近已提交的旧参考图。新增帧优先取同角色同类装备的已提交参考，再取其他角色比例相近的同类装备参考。按[参考 PNG 压缩流程](references/tools.md#压缩参考-png)核对后交付。批次、主题、候选编号与正式帧号的对应关系在交付时说明。用户明确指定其他目录时按指定目录交付。

所有魔物正式写入装备时，在子文件旁同步同主文件名的 `装备/A<母版名>_装备.xlsx`，例如 `A哥布林_装备.xlsx`。已有无 `A` 前缀的旧表时，先核实归属，改名后核对文件哈希。目标名称已存在时先核对两份登记内容。沿用同一工作簿的 `装备帧` 工作表，列为 `帧号`、`装备名称`、`装备类型`、`图层路径`，按子文件实际帧号升序登记。每套一行，类型填「套装」，列出该套实际使用的穿戴图层完整路径。同帧的独立单件按件分行，沿用已确认的名称与部位类型。补录时可从已确认预览、历史源文件或项目道具中文名核实，无法核实的名称标记「待确认」。修整或移帧时同步原记录并保留其他工作表。候选预览仅在临时目录登记；写回时将名表纳入同一批备份、回读和失败恢复，按[项目 Excel 规则](../../../CLAUDE.md#excel-读写规则)关闭工作簿并核对 Git 可读。之后[回填母版](../aseprite-master-backfill/SKILL.md#同步素材名字表)时，母版旁的 `<生物>_素材名字.xlsx` 按实际母版帧号和图层另行登记。

工作副本、部件 PNG、manifest、报告和对照图集中放在本次专用临时目录，验证后清理。

重新设计的套装用本次选定的角色全身实穿设计图制作同帧「参考」PNG。与之配对的「预览」PNG 从保存后重新打开的装备帧导出。

制作哥布林装备时，先读[哥布林母版适配](references/goblin.md)：其中记录已确认的身体优先约定、适用版本、部件坐标和原图取色检查。坐标只用于匹配版本的复核，不作为所有角色的固定模板。

## 先确定本次变化

- 读取用户指定母版。用户已经指定或确认过该角色的整身实穿图时，核对[披挂与双臂分层](#披挂与双臂分层)后沿用该版本。局部修整沿用认可的基准版本及参考图。首次制作缺少套装预览图时，按[像素图生成方式](../../../CLAUDE.md#像素图生成方式)确定本次流程。套装采用生图时，执行下方的生图与确认步骤。
- 确认每套装备在原参考图中的位置。拼图按对应格或实际边界裁出完整套装，单套原图可原样另存为临时 PNG。裁片保留原尺寸、像素、配色和背景，供装备取色与参考图压缩验收。局部修整沿用已确认的参考图。用户要求保留原像素时，按[无损优化方法](references/tools.md#无损优化参考-png)处理。

## 破碎套装的重制

后续需要重新设计的套装默认采用「生成角色整身实穿稿 → 选版 → 转为原生像素 → 在 Aseprite 精修」。用户另选方式时沿用其选择。批量任务按指定范围逐帧对照原款参考、装备单层和角色的原生 1× 穿戴图，必要时找回压缩前的参考并用最近邻整数放大。沿腰到裙摆、胸甲到护腹、握点到武器逐处找断边和穿插。按原款区分开衩、露肩、卷袖等有意设计与意外露底。如果原有细节在原生穿戴图上已经读成破洞或悬空碎片，记录帧号与部位并重新设计。

对有问题的套装，从原款提炼服装类型、主色和最有辨识度的饰件，重新编写生图提示词，说明衣片的裁剪、连接、覆盖范围和材质。允许改变领口、衣长、开衩、剪影和纹样密度。举例说，紫金术士可以保留尖帽和星扣，重新设计成有完整前襟的长袍。用选定实穿稿的衣片轮廓重新拆件；沿用旧装备蒙版硬裁会把旧断口带进新稿。用户委托按基本款式自由重新设计时，按此范围构思衣装，随后仍按[生图预览的生成与确认](#生图预览的生成与确认)选择实穿图、转成原生像素。用户只要求局部修整时，依其指定范围处理。

以新设计的大块衣片重新适配肩、腰、膝和手腕的实际锚点，在原装备层补足跨部位接缝和前后遮挡。去除纯色背景时，对照去背前后的剪影，特别留意与背景同色系的布料。用原生 1× 确认一眼能读出主体与关键饰件，再放大核对意外露底、穿插和碎高光。若缩小后仍破碎，合并衣片、删减纹饰或另出新稿，再以保存后的实穿图复查。

## 魅魔装备风格

魅魔的穿戴装备必须突出她性感、美丽、迷人的气质，礼服、战甲和职业服都遵循这条要求。用服装剪裁衬托母版已有的身形，在生图提示词中写明每款希望引人注意的部位，以及衣片如何引导视线。

- **剪裁与材质。** 例如，斜肩缎裙可以从锁骨的珠扣斜收至腰侧，再由开衩露出腿部线条。全覆战甲也可以用贴合腰胯的弧形甲片勾勒身段，以肩颈处的银边衬亮脸部。领口、露肤位置和覆盖程度随款式决定。
- **高级套装。** 为每款选一个醒目的工艺细节，例如腰侧的宝石搭扣或沿开衩延伸的刺绣。用成片的缎面亮光、丝绒暗部或金属镶边表现材质。批量设计时变化领线、腰线和下摆剪影，使各款在缩小后仍能区分。
- **选稿与复查。** 展示前将每款全身实穿图缩到母版角色的显示尺寸，逐款核对设计所强调的身体线条是否清楚、主要饰件是否衬托角色。若宽甲、厚袍或密集纹饰淹没了原定的线条或焦点，先修改该款剪裁再选版。拆件后在原生 1× 穿戴图上复核同一效果。

## 披挂与双臂分层

所有角色新制、重制套装或单件穿戴装备时，都按角色的实际肩、肘、腕和手掌定位。披风、披肩、长围巾的垂尾及其他悬垂衣片从双臂后方垂下，两侧腋下留出开口。从角色正面看，披挂不得横跨肩臂或遮住任一侧上臂、前臂、手掌。围巾的领圈、披风的胸扣可以贴在颈胸前，垂布沿肩后落下。

**选稿。** 把上述裁剪与前后关系写进实穿稿提示词。展示前沿左右肩分别看到手掌，确认两侧臂部轮廓和衣袖接缝都能辨认，腋下开口允许各自抬臂。实穿稿中任一侧手臂被披挂遮挡时，重新生成该款合格的实穿稿，再按选版流程确认、拆件。

**拆件与抬臂检查。** 披挂落到双臂之后的既有装备层，保留母版完整的左右臂。合体袖、随手臂转动的肩甲、护腕及手套按实际覆盖范围，分别拆入对应侧的上臂、前臂或手掌装备层。在预览副本分别抬起左臂和右臂，检查袖甲跟随肢体、披挂留在身后，腋下露出的衣片连续。沿用原有图层顺序和装备 Cel 的 Z 值 `0`。

## 生图预览的生成与确认

新生成的装备实穿参考图必须遵守[项目的像素风格要求](../../../CLAUDE.md#像素图生成方式)。展示选版前逐款查看原图，确认角色和穿戴件的像素颗粒一致。批量拼图中风格不符的款式单独重新生成。

1. 只读检查母版与目标装备帧，按[母版素模导出](references/tools.md#导出母版素模供生图参考)输出全身 PNG。已有套装按目标帧匹配身体比例、朝向、站姿、手足位置、发型、角和翼形，这些一致时可共用素模。给头饰、翼尖和脚底留足构图空间。
2. 把刚导出的目标角色全身素模 PNG 作为 ChatGPT 生图的实际图像输入。款式图可另附。让同一角色在原姿势下穿好整套服装，从头到脚同框，保留体型、头身比、朝向、倾角、四肢关节位置和种族特征。例如魅魔沿用实际母版的头部、角、双翼及其连接位置。检查衣领、袖口、腰线和裤脚在这个角色身上的落点。**严禁用隐形人台图或独立衣物绿幕图作为套装转绘来源。**
3. 展示新生成的实穿预览并标明版本，多套用编号或行列标明位置。等待用户明确确认使用哪一版、哪一套。若需调整，重新生图并展示新版本。确认前只做参考导出与预览。用户已指定或确认且双臂遮挡检查合格的实穿图可直接沿用。用户明确要求免选版时，可依其指令定稿。自由改款的授权只决定服装设计范围。
4. 将选定的实穿原图、版本和正式帧号一一对应。拼板逐格核对人物与款式，单套另出修订稿时用最后选定的原图转绘。采用「先生成图，再转为像素图」时，用[像素图编辑器](../pixel-image-editor/SKILL.md)等工具对齐母版画布、身体关节和像素网格，将整身实穿图重采样为原生尺寸的像素稿。选择「生图预览后用 Skill 重画」时，以同一实穿图在目标网格逐像素转绘。再以这份像素稿和实际母版身体分层为准拆件。若缺少该实穿图原图，先说明所缺输入。

## 选帧和装备图层

- 先检查母版与共用文件的画布、颜色模式、完整图层路径、各帧 Cel、偏移与遮挡。用该魔物原有同类装备的实际 Cel 建立部件与图层的对应关系，路径重名时用 `layer_indices` 定位。哥布林的帽子或头盔写入 `Hat_1`，胸衣写入 `Clothes_1`，其余见[哥布林装备图层](references/goblin.md#现有装备图层)。
- **一套一帧，各件分别写入对应的已有装备图层。** 同部位的不同款式复用同一层。按原有装备的拆件方式处理跨部位、左右件与配饰，禁止为套装、款式或单部件新建 `Equipment_*` 图层或一层铺整套。找不到对应层时，检查该魔物原有装备及遮挡；能按原例归入既有部件的照原例制作，仍无合适层时交代该部件的落位问题并继续可确定的部分。
- **新套装从最早的空装备帧开始补，有空位就复用，用完才在末尾追加。** 以当前共用文件检查占位，首次制作检查母版。只有该帧的所有既有穿戴装备层都没有 Cel，才可补入一套。可见与隐藏层均按实际 Cel 判断。单独的武器层在套装需要写入该层或用户要求武器一并为空时计入。批量按所选顺序使用依次最早的空位，保留原帧号、时长和标签，默认省略新标签。牛头人的独立鼻环按[鼻环图层补位规则](../aseprite-minotaur-backfill/SKILL.md#新帧的固定身体与落位)处理，除非用户明确选为该套的一部分，独立 `NoseRing_1` 不计入套装占位、预览或回填。
- 补入已有帧时保留该帧已有的身体、脸部和其他 Cel，只从核对过的基准补齐展示所需的空身体或脸部 Cel。末尾追加时复制该姿势所需的身体和脸部 Cel。基准复制排除旧装备、武器和 `Show` 等合成参考层。
- 修整已收录套装时定位其实际帧，修改该帧指定装备 Cel，更新对应预览，沿用已确认的参考图。明确要求并存的版本另占一帧，仍使用同一共用文件。修整尚未收录的历史套装时，按该魔物既有装备层拆件并收录一帧后再按帧维护。
- 配色和款式已认可、只需解决臃肿时，按[装备贴身修整](../../memory/reference_aseprite_equipment_fit.md)沿身体轮廓逐件收边，并检查原有遮挡、包边和饰件。
- `.aseprite` 的保存、图层和帧编辑只用官方 Aseprite CLI/Lua；Python 可处理独立 PNG，不写 `.aseprite` 二进制。工具定位和基础检查见 [aseprite-pixel-editor](../aseprite-pixel-editor/SKILL.md)。

## 美术制作

1. 导出母版角色组合及身体部件，定位头、颈、肩、肘、腰、膝、踝在原画布的坐标。对照原生实穿像素稿和各身体层的实际轮廓，判定哪些衣片压住身体、哪些藏在手臂、头发或腿后。只把衣物像素拆进对应的已有装备层。
2. 独立制作兜帽、披肩、胸带、腰带、腰裙、护腕、腿甲等所需部件，部件数量随设计确定。提取参考材质时去掉灰底、皮肤和相邻装备残片，拆分后逐件查看，不能只检查合成图。
3. 在 Aseprite 原生尺寸精修每件的色块、包边、接缝及被遮住的衣片。兜帽围绕原头部留出帽口并连接颈肩。护腕跟随前臂，关节甲对齐原膝肘。按原层序穿回角色，检查领口露肤、袖口交接、下摆和靴口是否符合选定的实穿图。
4. 延续参考的主光方向，分别建立布料、皮革、金属的暗部、主体和亮面；保留集中高光与接触阴影，避免随机碎色。要求接近原图配色、光照时，优先保留原图装备像素并分件适配，不用自选少量平涂色代替。未经允许不量化、合并近似色或整体调色，也不因用户说“清晰”就重做色板。已认可的配色优先。
5. 描边按[完美像素检查](../aseprite-pixel-editor/SKILL.md#完美像素检查)核对外轮廓、帽口、披肩下缘和部件接缝。用户只认可描边时，沿用该版边线和原稿内部细节。若同时要求整理碎色，按[保留原形的局部调色](../aseprite-pixel-editor/SKILL.md#保留原形的局部调色)逐件处理，再在实穿图上对照原有纹样、包边高光和材质分界。
6. 新制或按要求优化套装配色时，每套共用一份色板。同一色系跨所有穿戴件合计最多 5 种实际 RGB，包含高光、基本色和暗色。冰蓝和相近的青蓝共用色阶，中性灰从墨色到白合计。每个 RGB 只归入一个色系，同色系在不同部件或材质上共用名额。验收时回读所有穿戴 Cel，包括被遮住的部件，汇总每个 alpha 大于零的像素，按实际 RGB 去重，核对各色系的清单和数量。

## 重制后的逐帧穿戴复查

新制和修整也按[多件素材逐件制作与验收](../aseprite-pixel-editor/SKILL.md#多件素材逐件制作与验收)执行。特别是裹裙和拖尾，先在透明装备层检查腰扣、前摆和后摆的连接，再在穿戴图中沿开衩两侧追到裙脚；从两腿之间露出的后摆，应能在后层追溯到腰胯。穿戴后若髋侧出现原稿没有的缺口，按同坐标叠看腰封、前裙和大腿，检查大腿是否遮住了腰线。

把选定稿与从已保存 Aseprite 按实际层序导出的同帧实穿图并排看。先在原生 1× 辨认款式，再用最近邻整数放大查看接缝。发现异常时单看对应装备 Cel，与身体 Cel 按原坐标叠放，修完重新导出。

| 实穿图里的问题 | 原生尺寸下的修法与验收 |
| --- | --- |
| 胸衣轮廓完整，穿上却露出一侧胸口，或长袖旁仍看得见手臂 | 按选定稿圈出本应覆盖的区域，分别检查两侧胸、上臂和前臂。魅魔的 `Mimi_L`、`Mimi_R` 是独立身体层，画在 `Clothes_1_Body` 上的布面可能被盖住。把缺失衣片补在对应侧的胸衣层，袖管沿肩、肘、腕接到袖口。难判时与同坐标的原肤色像素比对，保留选定稿的领口、短袖和露臂。 |
| 腰部出现横向皮肤缝，或轻纱和靴口读成碎片 | 沿上衣、腰带、前后裙片追踪到下摆，在对应层补足重叠。把零散高光收成连续的褶线和包边，缩回 1× 核对开衩、靴口和露腿的位置。魅魔第 61 帧保留紫纱的两侧垂片，第 68 帧保留中幅金星。 |

若发现同一种遮挡或拆层错误，复查指定范围内所有采用这一结构的套装。已选定款式的漏底、断边和散点就在原生装备层修复。需要改变已选款式时才重新出稿选版。

## 组装、验证与交付

使用[工具与 manifest](references/tools.md)在临时副本组装，补空位和局部修整用 `replace`，无空位时用 `append`。每次写完一套，以该次输出为下一套的输入。所有魔物的装备沿用原有图层顺序和可见性，新装备 Cel 省略 `z_index`，修整或迁移套装时将涉及的旧装备 Cel 的 Z 归 `0`。该操作只涉及目标装备 Cel，身体、脸部和其他非装备 Cel 沿用原属性。母版装备层默认隐藏时，在预览导出中显示本套对应的装备层。

重新打开候选文件，核对每套各件在同一帧的预定图层且 Z 均为 `0`。核对原图层顺序与属性、未改 Cel 的像素、位置、透明度和 Z，以及帧时长和标签范围。按实际帧原生导出，在 1× 和最近邻整数放大下检查形状、接缝、透明边缘和遮挡。

按[装备帧身体核对](references/tools.md#装备帧身体核对)检查补位帧保留的身体 Cel、补齐的身体 Cel 和追加帧的身体 Cel，各与其实际来源一致。

写回前核对母版和共用文件的输入哈希。共用文件已有更新时，从最新版本重新排帧和生成相应文件名。先在同卷临时目录验收候选 Aseprite 与本批 PNG，再移入首次目标或用 `[System.IO.File]::Replace` 更新同一个源文件。修订时更新该帧涉及的 PNG，保留其他帧的图片。逐个核对正式文件可读、直接父目录与约定一致，以及两张 PNG 的帧号和参考来源与正式帧对应。保留本次替换的文件备份到整批核验通过，写回中途失败时恢复已替换的文件并清理本次新增文件。

用户要求清理已合并的旧文件时，先逐套核对正式帧及两张对应 PNG，再按已确认的套装清单删除旧单套 `.aseprite` 和旧命名配套图片。回读 `装备/`，确认共用源文件和按实际帧号保存的两张 PNG 齐全。

交付共用源文件、同目录装备帧名表，以及每套的实际帧号、装备图层和两张 PNG。需要回填母版时，将这份帧号与图层清单交给[母版回填](../aseprite-master-backfill/SKILL.md)。对应角色指南为 [aseprite-equipment-artist](../../agents/aseprite-equipment-artist.md)。
