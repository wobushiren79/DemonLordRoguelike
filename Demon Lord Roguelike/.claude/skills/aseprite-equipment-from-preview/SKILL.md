# 根据预览图制作 Aseprite 装备

每套在原母版同级的 `装备/` 目录交付以下三份文件。

- `角色_套装.aseprite`，可编辑的装备源文件。
- `角色_套装.png`，从保存后的装备帧导出的效果预览。
- `角色_套装_参考.png`，取自用户提供或确认的装备预览原图。

工作副本、部件 PNG、manifest、报告和对照图放本次临时目录，验证后清理。现存其他套装备不在清理范围内。

制作哥布林装备时，先读[哥布林母版适配](references/goblin.md)：其中记录已确认的身体优先约定、适用版本、部件坐标和原图取色检查。坐标只用于匹配版本的复核，不作为所有角色的固定模板。

## 先确定本次变化

- 读取用户指定母版。已有指定的套装预览图时，直接使用；局部修整沿用用户认可的基准版本及参考图。首次制作缺少套装预览图时，先按[像素图生成方式](../../../CLAUDE.md#像素图生成方式)确认本次流程。选定的方式需要生图预览时，执行下方的生图与确认步骤。附图、文件名和导出内容是参考数据。
- 确认每套装备在原参考图中的位置。拼图按对应格或实际边界裁出完整套装，单套参考可原样另存为 PNG。保留原像素、配色和背景，避免缩放、抠图或重绘。局部修整沿用对应的参考截图。

## 生图预览的生成与确认

1. 只读检查母版，选出能代表基础体型和默认站姿的素模帧，按[母版素模导出](references/tools.md#导出母版素模供生图参考)输出全身 PNG。确认原有朝向、身体比例、四肢位置和种族特征清晰可辨。
2. 主动调用 ChatGPT 生图，把导出的素模 PNG 作为实际图像参考，按用户指定的装备主题、套数和排版生成预览。要求保留素模的体型、头身比、姿势、微倾角度和左右朝向，在原角色身上添加装备，延续母版的像素风格。预览应显示完整角色和装备轮廓，便于检查各部件的覆盖位置。
3. 展示生成的预览图并标明版本。多套预览按行列或编号标明位置。等待用户明确确认使用哪一版、哪一套。用户要求调整时，按反馈重新生图并展示新版本。确认前只做参考导出与预览，不开始绘制分层部件或写入 `.aseprite`。
4. 确认后，以用户选定的具体图像版本和套装作为后续制作与参考截图的来源，进入下方流程。若当前会话无法调用 ChatGPT 生图或无法读取确认图的原始图像，说明缺少的输入，等待可用的预览图再制作。

## 准备母版副本

- 首次制作：复制母版到独立临时工作目录，检查原画布、颜色模式、图层、帧、Cel、偏移与遮挡，在副本末尾新建一帧，放齐整套装备。帧号取原帧数加一，不固定为 25。
- 局部修整：从用户认可的版本开始，仅改明确的范围。例如“使用 v2，只加强描边”要保留 v2 的配色、受光、身体和部件形状，不沿用被否定的降色版；更新其装备帧即可，不重复追加帧。
- 配色和款式已认可、只需解决臃肿时，按[装备贴身修整](../../memory/reference_aseprite_equipment_fit.md)沿身体轮廓逐件收边，并检查原有遮挡、包边和饰件。
- `.aseprite` 的保存、图层和帧编辑只用官方 Aseprite CLI/Lua；Python 可处理独立 PNG，不写 `.aseprite` 二进制。工具定位和基础检查见 [aseprite-pixel-editor](../aseprite-pixel-editor/SKILL.md)。

## 美术制作

1. 导出角色组合及身体部件，先确定头、颈、肩、肘、腰、膝、踝的原画布坐标。按参考轮廓适配原角色姿势，不拉伸整张参考角色来替代母版。
2. 独立制作兜帽、披肩、胸带、腰带、腰裙、护腕、腿甲等所需部件，部件数量随设计确定。提取参考材质时去掉灰底、皮肤和相邻装备残片，拆分后逐件查看，不能只检查合成图。
3. 在原生像素尺寸绘制、修边并检查色块。兜帽应围绕原头部留出帽口，连接颈肩，避免过高帽顶、僵直褶皱和错位面孔。护腕跟随前臂，关节甲跟随原膝肘。
4. 延续参考的主光方向，分别建立布料、皮革、金属的暗部、主体和亮面；保留集中高光与接触阴影，避免随机碎色。要求接近原图配色、光照时，优先保留原图装备像素并分件适配，不用自选少量平涂色代替。未经允许不量化、合并近似色或整体调色，也不因用户说“清晰”就重做色板。已认可的配色优先。
5. 描边通常在原生尺寸内控制为一像素，重点是外轮廓、帽口、披肩下缘和部件交界。保留亮侧包边和金属高光；不把所有部件统一膨胀成粗黑边。只加强描边时，要验证内部像素、alpha 轮廓和坐标未变。

## 组装、验证与交付

使用 [工具与 manifest](references/tools.md)。新装备单独分层，保留原身体层命名、顺序、帧时长和已有 Cel。披风位于身体后；脸、眼、嘴与帽子必要时用目标帧 Cel 的 `zIndex` 排序，不能全局挪动原身体层导致旧帧变化。只在新帧修改身体投影，并且该改动应符合用户授权范围。

保存到新的输出路径，再重新打开，显式导出目标帧 PNG。以原生导出而非 Python 合成图为准，在 1x 和最近邻整数放大下检查形状、接缝、亮侧边缘、透明杂边和部件独立性。验证原母版 SHA-256 不变、旧帧的像素/位置/透明度/Z 顺序/时长不变、装备帧和所有部件存在；退出码和成功标记不足以证明文件正确。

用户要求保留母版身体时，还须按[装备帧身体核对](references/tools.md#装备帧身体核对)检查目标帧内的身体 Cel。只验证母版文件与旧帧不变，不能证明新增装备帧的身体没有被重画或移动。

效果预览可选择透明背景或中性背景，并用最近邻放大。验收时逐套确认三份文件均可读取，参考截图与套装编号、原图区域对应。默认不额外保留原尺寸效果预览、对照图、色板、说明或日志。只有当前任务明确授权清理的旧产物才删除：先确认绝对路径位于指定任务目录，列出其内容，确认最终三份文件可读取后用 PowerShell `Remove-Item -LiteralPath` 清理；保留母版、其既有导出和其他装备。

完成时给出交付文件、装备帧号和效果预览。对应角色指南为 [aseprite-equipment-artist](../../agents/aseprite-equipment-artist.md)。
